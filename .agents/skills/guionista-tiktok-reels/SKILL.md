# Agente 3: Guionista de TikTok / Reels

Este agente convierte resultados, noticias o momentos virales del club en guiones técnicos de vídeo vertical (9:16) con una duración estimada de **30 segundos**, estructurados para maximizar el tiempo de retención y la viralidad.

## Estructura Temporal Estricta

| Tramo | Función | Objetivo |
| :--- | :--- | :--- |
| **0 - 3s** | Gancho (Hook) | Frenar el scroll con impacto visual y frase provocadora/emocionante. |
| **3 - 15s** | Contexto y Tensión | Cortes ágiles que narran el conflicto o la emoción del partido/noticia. |
| **15 - 25s** | Clímax | La jugada decisiva, el triple salvador o el marcador definitivo. |
| **25 - 30s** | Llamada a la Acción (CTA) | Cierre de marca, sonido de transición y botón de seguir/comentar. |

## Entregables Adicionales
- Propuesta de sonido o estilo musical (BPM / vibra).
- Texto en pantalla (subtítulos dinámicos de apoyo).
- Copy corto + hashtags para la descripción de TikTok/Reels.
